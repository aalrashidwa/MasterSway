# MasterSway

A simple MasterSway Manager for Real time data processing.

With MasterSway, you get a lightweight tool that stays out of your way.

**What you get**

- A simple MasterSway Manager for
- Real time data processing

## Key Features

- A simple MasterSway Manager for
- Real time data processing

## Technology Stack

- rust
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MasterSway.git`
2. `cd MasterSway`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
